# Validation — 1.1 Design system de base

## Périmètre

Cette campagne valide uniquement la page de démonstration exécutable du design system. Elle ne valide ni navigation applicative, ni écran métier, ni EPUB, ni audio, ni authentification.

La version reste `0.0.0`. Le rapport final d’une campagne doit citer le SHA complet réellement testé ; toute modification ultérieure rend les résultats concernés obsolètes.

## Installation reproductible

```powershell
corepack pnpm install --frozen-lockfile
```

## Contrôles automatiques

```powershell
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test
corepack pnpm build
corepack pnpm check:links
corepack pnpm check:secrets
corepack pnpm check:reference
corepack pnpm test:e2e
git diff --check
```

Les tests unitaires contrôlent les composants requis, les trois familles de pistes, les valeurs exactes des tokens, l’unicité des définitions de couleur dans le CSS et les familles typographiques. Les tests Chrome contrôlent les deux dimensions configurées, l’absence de débordement horizontal, le chargement des polices, la direction RTL, le focus visible et les erreurs de console.

## Contrôle visuel humain

1. Lancer `corepack pnpm dev`, puis ouvrir <http://127.0.0.1:5173> dans Chrome.
2. Vérifier que les onze couleurs figées sont visibles et correctement libellées.
3. Vérifier que SFX, Ambiance et Musique ont chacun une couleur, un libellé et une icône distincte.
4. Vérifier les états normal, survol, focus et désactivé des contrôles concernés.
5. Parcourir la page au clavier depuis le lien d’évitement jusqu’aux boutons, au champ et aux filtres.
6. Vérifier que la page de livre reste claire, en Literata, sur l’interface sombre.
7. Vérifier que le passage arabe est lisible, en serif arabe, et dirigé de droite à gauche.
8. Répéter à largeur de bureau normale puis à largeur réduite ; noter tout chevauchement ou débordement.
9. Ouvrir la console Chrome et consigner toute erreur.

Utiliser les statuts `PASS`, `FAIL` et `BLOCKED` définis par le [protocole](README.md). Une revue esthétique ou métier finale par le propriétaire du produit reste distincte des contrôles techniques automatisés.
